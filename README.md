# ksa-shoes-store

Storefront demo for a Saudi footwear retailer: Arabic and English, product grid, product pages, cart and checkout. Runs on local demo data; there is no backend or real payment.

Live: https://ksa-shoes-store.vercel.app

## Stack

Next.js 16 (App Router), JavaScript, Tailwind CSS.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```
